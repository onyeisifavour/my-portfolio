A few reminders that helped while putting this site together:

## Prefer server by default

Fetch content on the server. Reach for `"use client"` only when you need state, effects, or browser APIs — like the Projects / Blog tabs.

## Keep routes boring

- `/` for the portfolio surface
- `/blog/[slug]` for articles
- Query params (`?tab=blog`) for lightweight UI state you want to share

## Cache intentional reads

With Cache Components enabled, wrap filesystem reads in `"use cache"` so post listings stay part of the static shell instead of turning into request-time work.

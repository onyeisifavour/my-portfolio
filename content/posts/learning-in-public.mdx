I used to treat learning as private work — notebooks, half-finished Gists, and tabs I never reopened. That made progress hard to see and even harder to reuse.

This blog is a lightweight counterweight. Each post is a short note from something I was actually building or debugging.

## What belongs here

- Patterns I want to remember
- Tradeoffs I almost got wrong
- Setup notes that would save future-me twenty minutes

## What doesn't

Long tutorials rewritten from docs. If the official docs already explain it well, I'll link them and move on.

Writing forces clarity. If I can't explain a concept in a few paragraphs, I probably don't understand it yet.
